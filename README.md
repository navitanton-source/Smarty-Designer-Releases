# Smarty Designer — релизы плагина Android Studio

Это **публичный репозиторий готовых сборок** Smarty Designer. Исходный код плагина находится в приватном [Smarty-Designer](https://github.com/navitanton-source/Smarty-Designer). Мобильное приложение Smarty обновляется через другой репозиторий, [Smarty-Releases](https://github.com/navitanton-source/Smarty-Releases); смешивать эти каналы запрещено.

## Статус

Первая запланированная версия — **0.1.0**. Исполняемый ZIP ещё не создан и не опубликован, поэтому **автообновление пока не работает**.

После проверки и публикации первой версии здесь появятся:
- GitHub Release `designer-v0.1.0` с файлом `smarty-designer-0.1.0.zip` и `SHA256SUMS`;
- файл `updatePlugins.xml` в ветке `main` — каталог пользовательского репозитория плагинов JetBrains.

Адрес будущего каталога:

```text
https://raw.githubusercontent.com/navitanton-source/Smarty-Designer-Releases/main/updatePlugins.xml
```

**Не добавляйте этот адрес в Android Studio, пока файл не опубликован.**

## Установка и обновление

После публикации первой версии откройте в Android Studio:

`Settings → Plugins → ⚙ → Manage Plugin Repositories → +`

Добавьте указанный выше HTTPS-адрес `updatePlugins.xml`, найдите Smarty Designer и установите из подключённого репозитория. В настройках плагина проверьте источник `Updates from`; настройка автоматических обновлений находится в разделе Plugins.

Проверка реального обновления требует **двух** опубликованных версий: установки 0.1.0 и обнаружения/установки следующей версии. Установка ZIP с диска сама по себе не доказывает работу автообновления.

## Безопасность

В этот репозиторий допускаются **только утверждённые скомпилированные ZIP, SHA-256, каталог обновлений и документация**. Нельзя публиковать исходники, рабочие базы Smarty, фотографии, персональные данные, пароли, токены, APK мобильного Smarty или другие внутренние артефакты.

Выпуск разрешён только после ручного подтверждения владельца, сравнения с проверенным приватным черновиком и контроля SHA-256. Подробные правила: [RELEASE_POLICY.md](RELEASE_POLICY.md).
