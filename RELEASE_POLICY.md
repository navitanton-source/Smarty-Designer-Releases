# Правила выпуска Smarty Designer

1. Исходники и сборка хранятся **только** в приватном `navitanton-source/Smarty-Designer`. Целевая IDE владельца: Android Studio Rabbit 2 (2026.2.2 Patch 1), `AI-262.10968.63.2622.16840690`.
2. Codex реализует плагин; инфраструктура в приватном репозитории собирает и проверяет ZIP. Версия плагина независима от версии мобильного Smarty.
3. После ручного одобрения создаётся приватный **draft release** с названием `designer-vX.Y.Z`, файлом `smarty-designer-X.Y.Z.zip` и `SHA256SUMS`. Черновик не является публичным источником обновлений.
4. Отдельный защищённый workflow `plugin-publish-update.yml` из приватного проекта принимает точную версию и утверждённый SHA, сверяет имя, manifest `plugin.xml`, совместимость IDE и SHA-256 ZIP. Он использует только **проверенные байты**, а не пересобирает приложение перед публикацией.
5. После проверки публичная версия размещается в `Smarty-Designer-Releases` с тегом `designer-vX.Y.Z`. Публичное скачивание ZIP по HTTPS должно работать **без авторизации**.
6. **Только после успешной проверки скачанного ZIP и контрольной суммы** workflow меняет `main/updatePlugins.xml`, который используется Android Studio для обнаружения обновлений.
7. Обновление каталога не должно откатывать версию или подменять уже опубликованный ZIP с тем же номером. Если выпуск есть, а каталог не обновился, допускается повторный запуск только с идентичными байтами и исходным SHA.
8. Публикация использует отдельный fine-grained токен, ограниченный **только этим репозиторием**, с разрешением `Contents: Read and write`. Его значение хранится в GitHub Secrets **приватного** `Smarty-Designer` как `DESIGNER_RELEASE_PUBLISH_TOKEN`. Токен `Actions-Billing-Router` использовать для этого запрещено.
9. Реальный PASS автообновления подтверждается только проверкой перехода 0.1.0→0.1.1 в установленной Android Studio.

**Состояние: 11.11.2026 — только инфраструктура. Публичных ZIP и рабочего каталога обновлений пока нет.**
